# emitter

`make test` 跑全部自检（单元测试 + 精度扫描基准 + 审计查询）。

## 池满策略

- `POLICY_DROP`：旧策略，池满即丢弃新粒子（谁满丢谁）。
- `POLICY_EVICT`：按贡献分淘汰。池满时给全池打分，最低分者被淘汰；
  若新人自己分最低，则拒绝新人（同样记审计）。平局保留在位粒子。

## 贡献模型

三项因子各自归一化到 [0,1]：

| 因子 | 含义 | 计算 |
|---|---|---|
| life | 剩余寿命比例 | `1 - age/life` |
| area | 屏幕占比 | `size² × 边缘衰减 / 归一常数`，半径用 VIEW_R 归一 |
| bright | 亮度 | `bright × 随龄衰减包络`（出生满亮度） |

## 精度档位与权重反解

五档 L0–L4，每档给出三项的量化 bin 数（0/1 表示该项禁用）和
不同的近似数学预算（无 sqrt / Newton 迭代 / sqrtf / sqrtf+powf /
每帧全量重打分）。

权重按逆方差从 bin 数反解：均匀量化噪声方差与 `1/B²` 成正比，因此

```
w_k = B_k² / Σ B_j²
```

| 档 | bins(life,area,bright) | 权重 |
|---|---|---|
| L0 | (2,0,0) | (1.000,0,0) |
| L1 | (4,2,2) | (0.667,0.167,0.167) |
| L2 | (8,8,4) | (0.444,0.444,0.111) |
| L3 | (16,16,16) | (0.333,0.333,0.333) |
| L4 | (256,256,256) | (0.333,0.333,0.333) |

## 两条精度曲线（`bench` 输出）

1. 淘汰质量 vs 精度：同一次 160 粒爆炸重放下，留存粒子的双精度参考
   平均贡献；以及纯量化探针的 Kendall τ（固定同模型、等权，只变 bin，
   τ 随精度严格单调）。
2. 每帧额外耗时 vs 精度：单粒子评分 ns 数，以及端到端每帧相对旧策略
   的额外 μs（多轮中位数）。L4 的每帧全量重打分是主要成本台阶。

联合选型规则：取质量增益覆盖 L0→L4 跨度 ≥90%、且额外帧耗时不超过
L4 一半的最低档（当前测量结果为 L2）。测量数据写入
`../artifacts/precision_curves.csv`。

## 审计

每次淘汰/拒绝写一条审计记录（环形缓冲 `AUDIT_CAP`，溢出计数）：
帧号、事件类型、被淘汰粒子编号与新人编号、三项原始因子、双方分数、
原因码、档位。原因码可由日志里的因子独立重算并校验一致。

`./audit_query [粒子编号...]` 按编号查询；查不到即说明该粒子从未被
淘汰/拒绝（自然死亡或仍存活），不存在对应淘汰原因。
