# mini-vfx-lab

粒子与特效基础模块，C 实现，每目录独立构建可自测。

| 目录 | 目录内容 |
|---|---|
| `emitter/` | 速率与爆发发射、寿命过期、容量丢弃 |
| `field/` | 重力、线性阻力、涡流力场积分（Euler `step` + velocity-Verlet `step_verlet`） |
| `trail/` | 按年龄排序的轨迹点、宽度衰减 |
| `sim/` | 帧时钟（ms→s）与三模块串联的组合层，含各环节量纲探针 |
| `audit/` | 时间量纲自动审计与报告（`REPORT.md`） |

一键自检 + 量纲审计 + 60fps 自由落体验收：

    make test

验收判据：60 fps 下自由落体 1 秒，位移须落在 4.85–4.95 m（解析解 4.9 m，
相对误差 ≤ 1.02%）。
