# trail 采样实验

验证 `docs/sampling.md` 的推导：位移采样系数窗口、曲率边界与固定点数模式。

## 构建运行

```
make run        # 编译并跑三档速度实验，输出区段速度边界
make test       # 回到上级目录跑单元测试（cd .. && make test）
```

产物：

| 文件 | 内容 |
|---|---|
| `run_experiment.c` | 阿基米德螺线 + 切线弹射两段轨迹，解析 v/a 喂给生产采样器 |
| `coef_sweep.csv` | c ∈ [0.6, 3.3] 扫描：断裂段数、点数、重叠违规 |
| `coef_curves.html` | B(c) 与 N(c) 两条曲线（小多图，共享横轴，标注可行窗口） |

## 轨迹与解析量

`R = R0 − bφ`，`φ̇ = W = 1.5`，收紧到 R=0.5 后沿切线直线飞出。

```
R' = -bW
v² = W²(R²+b²)
|v×a| = W³(R²+2b²)
ρ  = (R²+b²)^{3/2} / (R²+2b²)      # W 消去
```

## 验收结果（r=1，c=π/3，K=4）

| 档位 | v₀ | 断裂段数 | q<1 区段速度区间 [入口, 离开] |
|---|---|---|---|
| 低 | 9.01 | 0 | [1.638, 0.901] |
| 中 | 18.03 | 0 | [1.910, 1.250] |
| 高 | 30.05 | 0 | [2.292, 1.828] |

- 三档断裂均为 0；每档固定点数模式介入一次，区段内钉死 4 个点；
- 实测 q=1 入口速度与解析解相差 < 0.002（一帧离散误差）；
- 系数扫描：重叠违规在 c≈1.005 归零，断裂在 c>2 出现，可行窗口 `[π/3, 2]`。

## 调试备忘

解析导数的两个易错点（均由 double 精度中心差分独立裁决后才定稿）：

1. `R' = dR/dt = −b·W`，不是 `−b`（b 是对 φ 的收紧率，要乘角速度）；
2. 加速度 `x'' = −R·cosφ·W² − 2R'·sinφ·W`，`y'' = −R·sinφ·W² + 2R'·cosφ·W`。
