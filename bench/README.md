# bench — 10 组爆炸的分阶段计时与提交优化对照

复现「同屏 10 组爆炸、约 2 万存活粒子」的完整帧管线，把一帧拆成 6 个
阶段分别计时，并对照两种 GL 提交方式。

## 方法

- 模拟算法逐字沿用仓库原实现，仅放大容量：
  - `emitter`：槽位线性扫描 spawn、全数组 alive 清点（`MAXP` 64 → 2048/组）
  - `field`：`expf` 阻力 + `sqrtf` 涡流 + 重力积分，参数不变
  - `trail`：满槽 `memmove` 平移 + `tr_age` 结构体压缩（`MAXT=32` 不变）
- 10 个 emitter，每组每帧爆发 33 发、寿命 1s，稳态存活 20130 个粒子。
- EGL pbuffer 离屏上下文 + GLES2，`glFinish()` 把驱动/光栅时间计入提交段。
- 两版提交共用同一份顶点缓冲，**唯一差异是 draw call 方式**：
  - `naive`：每粒子一次 `glUniform*` + `glDrawArrays(...,1)`（20130 次/帧）
  - `batch`：颜色并入顶点属性，整屏一次 `glDrawArrays(...,20130)`（1 次/帧）
- 每版交替跑 4×60 帧取均值；另有两个隔离实验（固定顶点只变 call 数、
  粒子数扩展性曲线）。

## 结果（llvmpipe 软渲染，Ryzen 9700X，三次运行波动 ±10%）

| 阶段 | naive (ms/帧) | 占比 | batch (ms/帧) | 占比 |
|---|---:|---:|---:|---:|
| emit 发射/寿命/清点 | 0.129 | 1.2% | 0.116 | 2.6% |
| field 力场积分 | 0.059 | 0.6% | 0.062 | 1.4% |
| trail 轨迹维护 | 1.048 | 9.8% | 1.191 | 26.3% |
| cpu_pack 顶点装配 | 0.041 | 0.4% | 0.034 | 0.8% |
| upload bufferData | 0.034 | 0.3% | 0.027 | 0.6% |
| **draw 提交+光栅** | **9.428** | **87.8%** | **3.096** | **68.4%** |
| 整帧 | 10.740 | | 4.527 | |
| 帧率 | 87.6–93.1 fps | | 218.8–229.0 fps | |

模拟三阶段合计仅 ~1.3ms（约 11%），提交段占 ~89%。

## 瓶颈定位的关键实验

固定 20130 个顶点（光栅工作量不变），只改变每次 DrawArrays 携带的顶点数：

| 每批顶点数 | draw call 数 | 耗时 (ms) |
|---:|---:|---:|
| 1 | 20130 | 6.394 |
| 10 | 2013 | 2.637 |
| 100 | 202 | 2.078 |
| 1000 | 21 | 2.148 |

顶点完全一样，call 数降 100 倍，耗时降 3 倍。测出每次调用的固定开销
约 0.2–0.3µs（软渲染下；真实 GPU 驱动的 CPU 侧校验/命令封装通常更贵，
常见数 µs/次）。**时间跟着 draw call 数走，不跟着粒子物理量走。**

## 结论

瓶颈不在粒子本身，而在 GL 提交路径的**单次 draw call 固定开销**
（驱动状态校验 + 命令编码，软渲染下还有每调用一次的光栅器启动），
被每粒子一次提交放大到 2 万次/帧。2 万点精灵的实际光栅工作量在
真实 GPU 上不到 1ms。

优化只动提交阶段：把每粒子 uniform 换成顶点属性，20130 次 draw call
合并为 1 次。模拟侧（emit/field/trail）一行未改。

本机软渲染下实测整帧 10.74 → 4.53ms（2.37x），帧率 93 → 221fps。
真实 GPU 上 call 开销占比通常更高，预期收益更大；按现场 18fps
（55.6ms/帧）中约 88% 为提交固定成本估算，合批后应回到 60fps 量级。

## 环境说明

WSL2 无 DRI3 加速，Mesa 回退 llvmpipe 软渲染，绝对帧率与真机不可比，
但「固定开销 × call 数」的成本模型与平台无关，隔离实验已排除光栅工作量
这一混淆变量。

## 后续候选（本次未动）

`trail` 是模拟侧最大头（~1.1ms）：每个存活粒子每帧一次满槽 `memmove`
（31 个点）+ `tr_age` 结构体压缩。可用环形缓冲 + 年龄游标消除搬移，
但它比提交段小一个数量级，按要求本次只优化瓶颈阶段。

## 运行

```
make        # 构建 bench
./bench     # 输出分阶段计时、合批对照、两个隔离实验
```
