## 风

`(wx, wy)` 是环境空气速度，不是加速度。粒子的 `(vx, vy)` 存的是**相对空气速度**：
阻力、涡流作用在它上面，风只在积分位置时叠加。这样即使有阻力，横向位移也严格等于
`风 × 年龄`。

风在**生成时采样一次并随粒子存储**（`part_spawn`），之后每帧都读同一个值。
这是刻意的选择，两种模型不能混：

| 模型 | 风 | 横向位移 | 轨迹 |
|---|---|---|---|
| 生成时采样一次 | `w(t) = w0` | `Δx(T) = w0·T` | 直线 |
| 每帧都采样（时变场） | `w(t) = w0 + αt` | `Δx(T) = w0·T + αT²/2` | 抛物线 |

把风当加速度累加进 `vx` 会得到 `w·T²/2`，量纲上就错了，自检 `wind_drift_3x1s`
会失败。

### 从截图判别当前实现

零阻力下：

- 生成时采样：所有点共线，`Δθ = 0`，弦高 `h = 0`。
- 每帧采样：端点切线与起点切线夹角 `Δθ = atan((w0+αT)/u) − atan(w0/u)`，
  弦高 `h = (αT²/8)·|sin β|`，`β` 为风轴与首尾弦的夹角。

`field` 自检里的量化判据（`u=2, w0=2, α=4, T=1`）：

- `Δθ < 0.02°` 且 `h < 0.01` → 生成时采样（直线）。
- `Δθ > 17°` 且 `h > 0.10` → 每帧采样（曲线）；解析值为 `26.565°` / `0.2236`。

注意：每帧采样但风是常量场（`α=0`）时轨迹仍是直线，单看形状无法区分，
只能靠换 `dt` 后位移是否改变来判别（自检 `wind_dt_independent`）。
