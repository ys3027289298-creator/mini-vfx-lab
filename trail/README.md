# trail

`make test` 跑自检。

## 模块

| 内容 | 位置 |
|---|---|
| 年龄排序轨迹点、宽度衰减（原有） | `src/trail.c` 上半部分 |
| 位移采样器：等弧长发点、曲率 q<1 区段固定点数 | `src/trail.c` `Sampler` 部分 |
| 系数推导与曲率边界 | `docs/sampling.md` |
| 三档速度实验、B(c)/N(c) 曲线 | `experiment/`（见该目录 README） |

采样间隔按位移而非时间：间距 `Δs = c·r`，系数窗口 `c ∈ [π/3, 2]`；
曲率半径 `ρ < r` 的区段几何上必然自重叠，改用固定 `K` 点采样。
