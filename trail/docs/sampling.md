# 拖尾位移采样：系数推导与曲率边界

## 1. 问题：按时间采样为什么会打结

旧方案每隔固定时间 `Δt` 采一个点。相邻采样点之间的轨迹弧长为

```
Δs = v · Δt
```

- **高速**：`v` 大 → `Δs` 大，点与点之间露出空隙，拖尾断成几段；
- **低速**：`v` 小 → `Δs` 小，点间距小于粒子尺度，粒子在涡流里来回抖动时相邻点反复堆叠，画成一团乱麻。

病根是采样间隔绑在时间上，而重叠/断裂都是**几何**现象，只和点之间的位移有关。因此把间隔改成弧长（位移）的函数，让时间间隔随速度变化：

```
Δs = c · r          （r = 粒子半径，c = 无量纲间隔系数）
Δt(v) = c · r / v   （采样间隔写成速度的函数）
```

在线实现不需要真的改帧率：每帧累加位移 `Σ v·dt`，攒够 `c·r` 就发一个点。这样高速低速单位弧长上的点数恒定。

## 2. 不重叠条件与系数反解

### 2.1 直线极限

轨迹为直线时弦长等于弧长。相邻点不重叠（相切允许）的条件即题设：

```
Δs ≥ r   ⇒   c ≥ 1
```

### 2.2 圆弧上的弦长修正

轨迹是曲率半径 `ρ` 的圆弧，相邻点对应圆心角 `θ = Δs/ρ`，弦长

```
d = 2ρ · sin(Δs / 2ρ) = 2ρ · sin(c·r / 2ρ)
```

令曲率比

```
q = ρ / r
```

不重叠条件 `d ≥ r`：

```
2q · sin(c / 2q) ≥ 1
⇒  c ≥ 2q · arcsin(1 / 2q)          （式 A）
```

式 A 有解要求 `2q ≥ 1`，即 `q ≥ 1/2`（这是相邻两点严格不重叠的绝对几何底限，见 §3）。

在我们允许采样的区域 `q ≥ 1` 上，右端 `f(q) = 2q·arcsin(1/2q)` 对 `q` 单调下降：

| q = ρ/r | 要求的 c 下限 |
|---|---|
| 1（最紧弯） | `2·arcsin(0.5) = π/3 ≈ 1.0472` |
| 2 | `4·arcsin(0.25) ≈ 1.0100` |
| 5 | ≈ 1.0017 |
| ∞（直线） | 1.0000 |

**反解结论**：取与曲率无关的保守常数

```
c* = π/3 ≈ 1.0472
```

即可在所有 `q ≥ 1` 的区段保证弦长 `d ≥ r`。直线工况下它只比最小间距多 4.7% 的冗余。

## 3. 绕不过去的边界：曲率比下限

### 3.1 比值与下限

拖尾是沿轨迹向两侧各展开 `r` 的一条带（ribbon，半宽 = 粒子半径）。轨迹的内缘等距偏移线在

```
ρ < r  即  q < 1
```

时产生尖点（offset curve cusp）：内缘偏移量超过了曲率半径，带状体自我折叠。**这是连续几何本身的性质，与采样间隔无关——`c` 取多少都消不掉重叠。** 因此曲率比的下限为

```
q_min = 1
```

### 3.2 相邻点视角的交叉验证

只看相邻两个采样圆盘（半径各为 `r`），弦长条件 `d ≥ r` 有解要求 `q ≥ 1/2`：

- `q < 1/2`：相邻点无论怎样间隔都互相侵入，点层面也无解；
- `1/2 ≤ q < 1`：相邻点可以不侵入，但非相邻点随采样加密必然在折叠区内相遇，带状体仍然打结；
- `q ≥ 1`：式 A 给出可行间隔，正常位移采样。

两个阈值对应两层失效，工程上采用更严格的 `q_min = 1` 作为模式切换线。

### 3.3 低于下限的区段：固定点数采样

`q < 1` 区段放弃等弧长加密，改用**固定点数**模式：进入区段时缓存原始帧，离开时把该区段的折线按等弧长重采样为固定的 `K` 个点。

- 重叠在几何上不可避免，继续加密只会把钱花在必然互相覆盖的点上；
- 点数被钉死为 `K`，每帧开销有上界，不会"点数爆掉"。

离散轨迹上的曲率用速度与加速度估计：

```
κ = |v × a| / |v|³ ,   ρ = 1/κ = v³ / |vx·ay − vy·ax|
```

## 4. 两条曲线定系数：断裂段数 vs 点数上限

`c` 不能只满足不重叠下限，还要防止拖尾断裂。两个半径 `r` 的圆盘相切不断裂要求弦长 `d ≤ 2r`。直线极限最严：

```
Δs = c·r ≤ 2r  ⇒  c ≤ 2
```

（弯道上弦长小于弧长，约束更松，`c ≤ 2` 是全局有效上界。）

于是系数可行窗口为

```
π/3 ≈ 1.0472 ≤ c ≤ 2
```

两条随 `c` 变化的曲线：

1. **断裂段数曲线** `B(c)`：相邻采样对中弦长 `> 2r` 的对数。`c ≤ 2` 时 `B(c) = 0`，超过 2 后随 `c` 快速上升；
2. **点数曲线** `N(c) = L / (c·r)`：长 `L` 的轨迹（或拖尾窗口）所需点数，随 `c` 双曲下降。

给定单条拖尾的点数预算 `N_cap`，点数约束给出 `c ≥ L/(r·N_cap)`。选系数规则：

```
c = clamp( max(π/3, L_window /(r·N_cap)),  π/3,  2 )
```

- 若算出的 `c > 2`：预算本身放不下一条不断裂的拖尾，必须缩短拖尾窗口或增大预算，无解不能靠调 `c` 掩盖；
- 预算充足时取窗口左端 `c = π/3`：点最密、连续性最好，且不违反任何不重叠条件。

## 5. 实现要点（src/trail.c）

1. **正常模式按"距上一输出点的圆交点"发点**：每个仿真帧是一条线段 `p0→p1`，求它与"以上一输出点为圆心、`c·r` 为半径的圆"的交点，在交点处插值发点。间距精确等于 `c·r`，且粒子沿振荡路径回摆时线段若不与圆相交就不发点，从机制上杜绝来回抖动造成的堆叠。
2. **曲率用 `κ = |v×a|/|v|³` 估计**：生产入口 `smp_update` 由位置做有限差分重建 v/a；实验入口 `smp_update_va` 直接吃解析导数。
3. **q<1 区段固定点数**：进入时缓存原始帧（环形缓冲，满了就地二分压缩，不丢轨迹），离开时对缓存折线做等弧长重采样，固定输出 `K` 个点；`smp_finish` 在粒子/拖尾结束时强制 flush 未闭合区段。
4. **滞回**：进入阈值 q<1，离开阈值 q>1.15，避免在边界附近反复切换模式。
5. **系数钳制**：`smp_init` 把 c 钳在 `[π/3, 2]`；预算规则 `smp_pick_coef` 按 §4 反解。

## 6. 三档速度实验（experiment/）

轨迹：阿基米德螺线 `R = R0 − bφ`（`φ̇ = W = 1.5`）收紧到 R=0.5，随后沿切线直线飞出。
螺线曲率半径（推导见下，W 最终消去）：

```
v² = W²(R²+b²),  |v×a| = W³(R²+2b²)
ρ  = (R²+b²)^{3/2} / (R²+2b²)
```

三档结果（r=1，c=π/3，K=4，dt=0.002）：

| 档位 | v₀ | 断裂段数 | 正常模式重叠 | 解析 q=1 入口速度 | 实测入口 | 实测离开（=弹射速度） |
|---|---|---|---|---|---|---|
| 低 | 9.01 | **0** | 0 | 1.6393 | 1.6380 | 0.9011 |
| 中 | 18.03 | **0** | 0 | 1.9111 | 1.9099 | 1.2504 |
| 高 | 30.05 | **0** | 0 | 2.2926 | 2.2915 | 1.8275 |

- **三档断裂段数均为 0**，验收通过；
- 每档恰好进入一次固定点数模式，每区段固定输出 4 点（入口点 + 3 个重采样点）；
- 实测与解析 q=1 边界的速度差 < 0.002（一个仿真帧的离散误差），离开速度逐位相等；
- **曲率半径低于下限（ρ<r）区段的起止速度值**即上表后两列：低 [1.638, 0.901]、中 [1.910, 1.250]、高 [2.292, 1.828]。区段内速度仍在下降，离开发生在螺线结束、切入直线（ρ→∞）的弹射时刻。

## 7. 系数扫描两条曲线（coef_sweep.csv / coef_curves.html）

中档路径上扫描 c ∈ [0.6, 3.3]：

| 现象 | 理论阈值 | 实测位置 |
|---|---|---|
| 正常模式重叠违规归零 | c ≥ π/3 ≈ 1.047 | c ≈ 1.005（圆交点插值使弯道弦长略大于离散下界，略早于理论值） |
| 断裂段数开始出现 | c > 2 | c ∈ (1.995, 2.040)，从 0 跳到 52 |
| 点数 N(c) | L/(c·r) 双曲下降 | 186（c=0.6）→ 57（c=2.0）→ 32（c=3.3） |

两条曲线夹出的可行窗口与推导完全一致：**c ∈ [π/3, 2]**。取窗口左端 `c* = π/3` 时点最密、连续性最好且零重叠；c<1 区域重叠违规高达 182 个（对应"打结"），c>2 区域断裂随 c 增大单调恶化。预算受限时按 §4 的 `smp_pick_coef` 在窗口内右移，`c>2` 的预算无解必须显式暴露，不能靠放宽间距掩盖。
