# trail

弯刀刀光拖尾模块。`make test` 跑纯 C 自检；`make viz` 导出一次完整挥砍的
几何数据，用 Python 出诊断图、逐帧叠图并跑全 229 帧的轮廓超出校验。

```bash
make test     # C 单元自检（采样 / 年龄 / 宽度 / 速度模型 / 刀尖曲线）
make viz      # 生成 ../artifacts 下的图、GIF、containment 报告
```

## 问题：等时间隔取点 → 拖尾是一条不贴合弯刀的直线

旧实现只按 push 顺序存点，调用方通常每个固定时间步 push 一次。挥砍有明显的
加减速：等时间隔在慢段堆点、在快挥中段两个点隔着很长的弧，折线只能用一条
长弦切过弧面，于是看到的是“笔直”的一段，和弯刀以及刀尖真实轨迹都不贴合。

## 第一步：先记录一次完整挥砍的刀尖坐标

`./trail points` 用一个圆弧弯刀（刃弧半径 `CURVE_R=2.05`、刃长 1.0）和一次
smoothstep 加减速挥砍（带手部前刺/下沉）跑出刀尖轨迹，按位置记录
**17 个坐标**（`RECORD_SPACING=0.115`）：

见 `../artifacts/tip_points.csv` 与 `../artifacts/tip_curve.png`。
曲线本身是一道弧：首尾弦长约 1.65，轨迹离直弦的最大矢高约 0.31
（≈19% 弦长），**不是直线**。

采样策略改成**按刀尖位置 / 等弧长**：`tr_sample()` 只在刀尖从上一个记录点
走过 `spacing` 距离后补点，并在跨过长段时沿线段插值，保证相邻记录点距离
恒为 `spacing`。实际缎带用更密的 `RIBBON_SPACING=0.045` 保证平滑；
诊断用的“十几个点”用较粗的 `RECORD_SPACING`。自测里验证了：

- 相邻记录点间距严格等于 `spacing`（`sample_uniform_gaps`）；
- 折线中点矢高不超过该弦长在圆上的理论弦误差 `sp²/(8R)`
  （`sample_curve_hug`）；
- 17 个点恰好落在“十几个”区间（`tip_records_dozen`）。

同等 8 点预算下，等弧长折线对密轨迹的最大偏离也小于等时间隔。

## 宽度：随年龄衰减，衰减曲线由刀速推出

每个点记录当时的刀尖速度 `v`，令速度比 `q = clamp(v/v_ref, qmin, qmax)`：

```
出生全宽  w0(v)   = base · min(1, q^-gamma)      挥得快 → 更细
寿命      τ(v)    = A · clamp(q^beta, lmin,lmax) 挥得快 → 年龄衰减更慢、留得更久
宽度      w(a,v)  = w0(v) · clamp(1 - a/τ(v), 0,1)^power
```

该点在衰减期间刀尖走过的空间长度约 `v·τ ∝ q^(1+beta)`，随速度快速增长，
所以**挥得快的地方拖尾更细、但在空间上拖得更长**。数值曲线见
`../artifacts/width_speed.png`（快 2.8：出生宽约 28 mm、空间尾长约 0.78；
慢 0.7：约 42 mm、0.09）。

## 叠回刀身 + 任何一帧的轮廓校验

`src/trail.c dump` 输出：密刀尖轨迹、17 个记录点、旧等时点、全部 229 个
仿真帧的刀身多边形，以及每一帧的缎带左右边界。`tools/render.py` 据此：

- 出 8 张关键帧叠图 `../artifacts/overlay_f0*.png`（灰色残影是该拖尾年龄
  窗口内的**刀身扫掠轮廓**）和总览 `overlay_sheet.png`；
- 出全流程动图 `../artifacts/overlay_swing.gif`；
- 对**全部 229 帧**，把缎带左右边界及横向截面细分采样，计算每个点到该帧
  年龄窗口内刀身扫掠多边形并集的距离，写入
  `../artifacts/containment.json` / `.txt`，并画
  `../artifacts/containment.png`。

当前结果：超出扫掠刀身轮廓的最大距离约 **0.021 世界单位 ≈ 9 px**
（门限 `D_GATE=0.035` ≈ 15 px），229/229 帧 PASS，`make viz` 在校验失败时
以非零码退出。

为什么基准是**扫掠轮廓**而不是“当前这一帧的刀身”：拖尾尾部记录的是若干帧
前的刀尖位置，快速挥砍时它本来就不在当前刀身上，而在“刀刚刚经过的地方”。
物理正确的“刀身轮廓”是近期刀身位置的扫掠并集（图中灰扇面）。报告里也保留了
到当前瞬时刀身多边形的距离作为参考量。
