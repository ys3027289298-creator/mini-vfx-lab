# pool

共享粒子池的属主隔离模块：可写区间判据、并发冲突审计、隔离粒度曲线。

```sh
make test    # 自检：裸池颜色污染复现 + 三档并发 + 196 个两系统配对零冲突
```

三档并发（`./pool tier 2|4|8`，各跑一次）结果：

| K | 选定粒度 g* | 冲突 | 颜色继承 | 峰值槽/完全隔离 | 含标签字节比 |
|---|---:|---:|---:|---:|---:|
| 2 | 4 | 0 | 0 | 104/128 = **0.8125** | 0.8379 |
| 4 | 4 | 0 | 0 | 156/256 = **0.6094** | 0.6284 |
| 8 | 2 | 0 | 0 | 192/512 = **0.3750** | 0.3984 |
