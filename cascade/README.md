# cascade — 子发射器级联的解析上界、阈值二分与十万粒子单帧计时

模型：TPS 风格的"粒子再发射粒子"。种子粒子按发射率 `R`（颗/秒）进入；
每颗粒子的寿命为 `L`，在寿命内每隔 `d` 秒发射 1 个子粒子；子粒子继承父粒子的
**剩余寿命**，并携带一条能量 `e`，子代能量 `e' = rho·e`（`0<rho<1`）。
只有 `e > theta` 的粒子才会发射 —— `theta` 就是触发阈值。

参数（`src/cascade.c` 里的 `default_params()`）：

| 量 | 值 |
|---|---|
| `L` 寿命 | 1.1 s |
| `d` 发射间隔 | 0.2 s |
| `k` 每颗粒子的子粒数 | `ceil(L/d)-1 = 5` |
| `rho` 能量衰减 | 0.8 |
| `E0` 种子能量 | 1.0 |
| `theta` 当前阈值 | **0（未设置）** |
| `R` 种子发射率 | 0.93 颗/s |
| `dt` 步长 | 1/120 s |

> 注：仓库原来的 `emitter/`、`field/`、`trail/` 三个模块里 **没有** 子发射器，
> 也没有任何"当前参数"。级联模型、参数与全部实测都放在本目录
> `cascade/`，参数集中在一个函数里，改那里即可。

## 1. 上界推导

### 1.1 每颗粒子产生多少子粒

粒子在 `age ∈ [0, L)` 内，发射时刻为 `d, 2d, 3d, …`。能落进寿命窗内的发射点数

```
k = #{ j ≥ 1 : j·d < L } = ceil(L/d) - 1
```

推导：`j·d < L  ⇔  j < L/d`，所以 `j` 可取 `1 … ⌈L/d⌉-1`，共 `⌈L/d⌉-1` 个。
当前参数 `L/d = 5.5`，`k = 6 - 1 = 5`。**这个 k 与层号无关**——每颗能发射的粒子
都恰有 k 个子粒，级联就是一棵每节点 k 叉的树。

### 1.2 树有多深

子代能量 `e_g = E0·rho^g`（g 为层号，种子是 g=0）。"能发射"只取决于
`e_g > theta`，于是存在一个最大可发射层号

```
g_max = max{ g ≥ 0 : E0·rho^g > theta }
      = ⌊ ln(theta/E0) / ln(rho) ⌋      （theta > 0 时）
```

- `g ≤ g_max` 的粒子发射 k 个子粒；
- `g = g_max + 1` 的粒子不发射，是叶子。

所以展开后的总层数是 `g_max + 2` 层（第 0 层到第 `g_max+1` 层）。

### 1.3 总数上界

一颗种子在**无穷长时间**内能产生的全部粒子（含自身）是等比级数：

```
N(种子) ≤ Σ_{g=0}^{g_max+1} k^g = (k^(g_max+2) − 1) / (k − 1)        (k > 1)
```

如果 `theta = 0`（不设阈值），`g_max = ∞`，上式**发散**：
`N ≤ k^G → ∞`。这是级联的"热失控"条件。

对一般发射率 `R`、观察时长 `T`（`R·T` 是种子数）：

```
出生总数 N_born(T) ≤ R · T · (k^(g_max+2) − 1)/(k − 1)
```

同一时刻的存活数还有一个不随 `T` 增长的上界：只有最后 `L` 秒内出生的种子
可能还活着，最多 `⌈R·L⌉` 颗，每颗贡献 `N(种子)`：

```
N_alive(任何时刻) ≤ ⌈R·L⌉ · (k^(g_max+2) − 1)/(k − 1)
长期均值          = R · L · (k^(g_max+2) − 1)/(k − 1)
```

再给一个**有限时窗更紧**的版本：第 g 层最早在 `g·d` 秒才可能出现，所以 T 秒内
最多展开到 `G = ⌊T/d⌋` 层（且不超过阈值给的 `g_max+1`）：

```
N_born(T) ≤ Σ_{g=0}^{min(G, g_max+1)} k^g = (k^(min(G,g_max+1)+1) − 1)/(k − 1)
```

这个版本不用等稳态；短时窗下它比 1.3 的无穷时窗式紧得多，且对 `theta=0` 的
短时窗能给出有限值。下面第 2 节发包时再乘上种子数 `R·T`。

**发散速率。** 每 `d` 秒前沿多一层，界乘 `k`，即每秒 ×`k^(1/d)`。
当前参数：`k=5, d=0.2` → 每秒 ×`5^5 = 3125`，约 8.05 个 e 折/秒，
倍增时间 `ln2 / (ln k / d) ≈ 0.086 s`。

## 2. 当前参数为什么会指数发散

当前 `theta = 0`，意味着 `e_g = 0.8^g > 0` 对所有 g 成立，`g_max = ∞`。
级联永远不会被能量截断，每一层都比上一层多 5 倍粒子，总粒子数随层数指数增长。
用 1.3 的时窗式（R=0.93 颗/s，纯种子）看界本身：

| T (s) | 可展开层 G | 单颗种子出生总数上界 |
|---|---|---|
| 1.0 | 5 | 3.9×10³ |
| 1.4 | 7 | 9.8×10⁴ |
| 1.6 | 8 | 4.9×10⁵ |
| 1.8 | 9 | 2.4×10⁶ |
| 2.0 | 10 | 1.2×10⁷ |
| 3.0 | 15 | 3.8×10¹⁰ |

值来自 `./cascade analyse` 的 `bound_within()`（单颗种子、时窗式）。
发芽种子数再乘 `R·T`，绝对数值大一个量级，增长模式相同。

界每 0.2s（一层）乘 5。也就是说，**不设阈值时，上界式本身就是发散的**——
粒子数随场景运行时长指数增长，任何固定容量的池都必然溢出。
实现里带 `MAXCAP` 上限，溢出部分计入 `dropped`，这正是"级联失控"的可观测症状。

> 补充：`per_spark_bound()` 在 `g_max` 达到 `MAXGEN-1`（即阈值小到 64 层都还能发射）
> 时返回 `INFINITY`，这是"界不可用、已发散"的显式标记。

## 3. 阈值二分：找最小可行阈值

目标：单颗种子的级联总数 `N(种子) ≤ 100000`。

`N(theta)` 是 `theta` 的**单调不增阶跃函数**：`theta` 越大，`g_max` 越小，
可展开层越少，`N` 越小。阶跃点在 `theta = E0·rho^g` 处——`theta` 只要略高于
`E0·rho^g`，第 g 层就整层被砍掉（一层相差 k 倍）。因此二分收敛后必须给出
"略低于 theta* 就超界"的证据，否则不能声称最小。

代码里 `bisect_threshold()` 在 `[0, E0]` 上二分（`theta=0` 不可行，
`theta≥E0` 可行），返回可行的最小端点。实测输出：

```
iter 0  mid=0.5       gmax=3  N=781
iter 1  mid=0.25      gmax=6  N=97656
iter 2  mid=0.125     gmax=9  N=12207031
iter 3  mid=0.1875    gmax=7  N=488281
...
theta* = 0.2097152000000001   (rho^7 = 0.20971520000000007)
gmax(theta*) = 6, levels = 8, bound = 97656   (target 100000)
minimality: theta 再低一点 (0.20971520000000007) -> gmax=7, bound=488281 (> 目标)
```

即 **theta\* = rho⁷ ≈ 0.2097**，`g_max = 6`，可展开 8 层。

### 用上界式验证

```
N ≤ (5^8 − 1)/(5 − 1) = 97656 ≤ 100000     ✓ 有界且达标
```

并且这是**按层精确相等**的：单颗种子实际出生总数正好 97656，逐层为
1, 5, 25, 125, 625, 3125, 15625, 78125（`./cascade verify` 的实测输出）。
所以 1.3 的界不只是宽松上界，在该参数下是紧的。

一般时间/发射率下的界（`./cascade analyse` 输出）：

```
出生总数  ≤ R·T·97656 = 9.08×10⁴·T           （线性于 T，不再指数）
存活瞬时  ≤ ⌈R·L⌉·97656 = 2·97656 = 195312
长期均值  = R·L·97656 ≈ 99902
时窗更紧的单种子界 T=3s: 97656              （3s 已能展开全部 8 层）
```

**关键对比**：无阈值时界随 T 指数爆炸（T=3s 已 3.8×10¹⁰）；
theta* 下界只随 T **线性**增长，瞬时存活有固定上限。指数发散被消除。

> 关于"进制阈值":theta 是阶跃函数，`theta ∈ (E0·rho^7, E0·rho^6]` 这一段里
> N 恒为 97656；二分会稳定收敛到该段的**下边界** `rho^7`（严格说略高一点点，
> 因为要求 `e_7 = rho^7 ≤ theta` 以砍掉第 7 层）。这就是该目标下的最小阈值。

## 4. 十万粒子单帧 ≤ 4ms（计时器实测）

`./cascade bench`：在 theta* 下以 `R=0.93/s` 稳定运行，用 `CLOCK_MONOTONIC`
在 `w_step()` 内部四个阶段各埋一个计时点，统计 10–18 s 的 960 帧（已跳过 10 s 暖机）。

计时点：

| # | 阶段 | 位置 |
|---|---|---|
| t0 | 帧开始 | `w_step()` 进入，`now_sec()` 取 `CLOCK_MONOTONIC` |
| t1 | 推进 + 过期（swap-remove） | 所有粒子 age/x/y 更新完 |
| t2 | 子发射 | 子粒子写满 child 缓冲 |
| t3 | 种子发射 | 按 rate 补种子 |
| t4 | 并回粒子池 | `memcpy` 进池，帧结束（总耗时 = t4−t0） |

代码位置：`cascade/src/cascade.c` 的 `w_step()`，每个计时点在数组
`last_us[0..4]` 里，`bench()` 逐帧收集后做分位数统计。

## 关于模型的一个细节

`k = ⌈L/d⌉ - 1` 而不是 `⌊L/d⌋`：`j·d < L` 是严格不等号，此时 `j` 能取到
`⌈L/d⌉-1`。例如 `L/d = 5.5`，`j=1..5` 共 5 个发射点，`⌊L/d⌋` 也恰是 5；
但若 `L/d = 6.0`，`j=1..5` 仍是 5 个（第 6 个在 `age=L` 处已不可见），
`⌈6⌉-1 = 5`，而 `⌊6⌋ = 6` 会多算一个。实现里用 `ceil(q-1e-9)-1` 正是为了
处理恰好整除的浮点情形。
