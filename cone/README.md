# cone

锥内方向采样：角度均匀（有偏）对照与立体角均匀（无偏）采样器，含卡方检验。

- `src/cone.c`：C 参考实现与自检，`make test`
- `analysis/cone_sampling.py`：纯标准库统计实验（`python3 -I analysis/cone_sampling.py`）

## 1. 两种采样的径向密度

锥轴取 z 轴，方向记为 (θ, φ)，锥半角 α，立体角微元 dΩ = sinθ dθ dφ。

**方法 A — 角度均匀（有偏）**：θ ∼ U[0,α]，φ ∼ U[0,2π)。
θ 的边缘密度 f_A(θ)=1/α，单位立体角密度为

  w_A(θ) = f_A(θ) / (2π sinθ) = 1 / (2πα sinθ)

**方法 B — 立体角均匀（无偏）**：cosθ 在 [cosα, 1] 上均匀。
令 c=cosθ，f_c(c)=1/(1−cosα)，由 dc=−sinθ dθ 得单位立体角密度

  w_B(θ) = 1 / (2π(1−cosα)) = 1/Ω，Ω=2π(1−cosα) 为锥立体角，与 θ 无关。

**密度比（A 相对 B）**

  R(θ) = w_A/w_B = (1−cosα)/(α sinθ)。

∂R/∂θ 的符号与 −cosθ 相同，故 R 在 (0,α) 上单调递减：
**最大值在锥轴 θ→0 处**，R→ (1−cosα)/(α·θ) → ∞（可积奇点）；
**最小值在锥面边缘 θ=α**，R(α) = (1−cosα)/(α sinα)。

实测边缘比值：α=15° → 0.5029，30° → 0.5117，45° → 0.5274
（与实测边缘环/无偏环计数比 0.510、0.524、0.532 吻合）。
小角度下边缘只比无偏稀疏约一半，但轴附近是发散奇点——中心环（占立体角 1/10）
吃掉约 31% 的样本，边缘环只拿到约 5%。

## 2. 无偏采样器及其证明

```
u0, u1 ~ U[0,1)
cosθ = 1 − u0(1 − cosα)        // 即 θ = acos(1 − u0(1−cosα))
φ    = 2π u1
方向  = (sinθ cosφ, sinθ sinφ, cosθ)
```

**无偏性证明**：要证 P(方向落入 dΩ) ∝ dΩ，即 w(θ) 为常数。
令 c=cosθ。构造给出 c = 1 − u0(1−cosα)，u0 均匀 ⇒ c 在 [cosα,1] 上均匀，
f_c(c)=1/(1−cosα)。变量 (c,φ) 与 (θ,φ) 的雅可比为 |dc|=sinθ dθ，故

  f(θ,φ) dθ dφ = f_c(c) · (1/2π) · sinθ dθ dφ
               = sinθ dθ dφ / [2π(1−cosα)]
               = dΩ / Ω。

即任一立体角微元被命中的概率恰为 dΩ/Ω，正比于其立体角，证毕。
α=π 时 cosθ=1−2u0，退化为整球均匀采样（cosine-weighted 的标准形式）。

## 3. 实验与卡方检验

N=100000 个样本/组，投影到单位球面后按 **10 个等立体角环 × 4 个方位扇区 = K=40 桶**
分桶（环边界 cosθ_j = 1 − j(1−cosα)/10，每桶立体角严格相等）。
H0：各桶等概率，期望计数 E=N/K=2500。检验量

  χ² = Σ (O_k − E)² / E，  自由度 df=K−1=39，
  临界值 χ²_{0.95}(39) = 54.5722（自实现正则化上不完全伽马函数二分求根，
  与 df=1/10/39/40 的表值核对一致）。

| 锥角/采样 | χ² | 临界值 | p 值 | 结论 |
|---|---|---|---|---|
| 15° 角度均匀 | 58036.60 | 54.5722 | ≪0.001 | 拒绝均匀 |
| 15° 立体角均匀 | 30.91 | 54.5722 | 0.819 | 不拒绝 |
| 30° 角度均匀 | 55902.59 | 54.5722 | ≪0.001 | 拒绝均匀 |
| 30° 立体角均匀 | 33.18 | 54.5722 | 0.732 | 不拒绝 |
| 45° 角度均匀 | 54379.86 | 54.5722 | ≪0.001 | 拒绝均匀 |
| 45° 立体角均匀 | 31.55 | 54.5722 | 0.796 | 不拒绝 |
| 180° 角度均匀（对照组） | 27987.32 | 54.5722 | ≪0.001 | 拒绝均匀 |
| 180° 立体角均匀（对照组） | 38.84 | 54.5722 | 0.477 | 不拒绝 |

## 4. 要求的对照表

「中间桶」= 最靠近锥轴的等立体角环（环 0），「边缘桶」= 最靠近锥面的环（环 9），
环内 4 个方位扇区求和；无偏时每环理论期望 N/10 = 10000。

| 锥角 | 边缘桶计数 | 中间桶计数 |
|---|---|---|
| 15°（角度均匀 / 立体角均匀） | 5100 / 10051 | 31730 / 9895 |
| 30°（角度均匀 / 立体角均匀） | 5244 / 10304 | 31388 / 9920 |
| 45°（角度均匀 / 立体角均匀） | 5320 / 9933 | 31066 / 9962 |
| 对照组 180°（角度均匀 / 立体角均匀） | 20558 / 9961 | 20247 / 10067 |

环 9 期望 5242.7，实测 5244——逐环偏差均在采样涨落内。
