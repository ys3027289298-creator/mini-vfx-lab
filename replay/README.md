# replay

粒子特效的录制 / 存档 / 回放，验证检查点必须存哪些状态才能保证回放确定性。

模拟由 `emitter`（速率 + 爆发发射、寿命过期、容量丢弃）与 `field`
（重力、指数阻力、涡流）组合，随机性全部来自一个显式状态的 xorshift32 RNG。
固定步长 `DT`、固定事件脚本，因此同一初始状态 + 同一事件流必然产出同一结果。

## 构建与验证

```bash
make          # 产出 ./replay
make test     # 等价于 bash verify.sh，跑完整端到端验证
```

## 子命令

```bash
./replay record <v1|v2> <save> <framelog>      # 录制 90 帧，第 20 步后写检查点
./replay play   <v1|v2> <save> <framelog> [seed]
./replay hole-test <workdir>                    # 池空洞还原对照
```

## 两个存档版本

### v1（缺陷版）—— 漏存状态

检查点只写 `meta`（n/计数器）和存活粒子（紧凑追加、丢弃死槽位）。
以下四类影响后续结果的状态全部缺失，加载时被回填默认值：

| 缺失状态 | v1 加载时的回填 | 后果 |
|---|---|---|
| RNG 种子/状态 `rng` | 命令行种子，否则 `time^pid^地址` 现取 | 每次回放拿到不同随机流，发射初速/寿命抖动全部分叉 |
| 发射器累积量 `rate_acc` | 清零 | 速率发射的小数进位错位，发射提前/滞后 |
| 力场参数 `field` | 全零 | 重力/阻力/涡流消失，检查点后第一帧粒子轨迹立即偏移 |
| 粒子池全量（含死槽位） | 只存存活粒子并压缩 | 槽位布局与容量高水位 `n` 被破坏，后续复用槽位错位 |

### v2（修复版）—— 补齐全部状态

```text
VFXSAVE v2
cp <帧号>
rng <uint32>                       # RNG 完整状态（种子即初始状态）
emitter <n> <emitted> <dropped> <rate_acc>   # 含累积量与池容量高水位
field <gx> <gy> <drag> <swirl>     # 当前力场参数
slot <i> <alive> <x> <y> <vx> <vy> <age> <life>   # 逐槽位，死槽位(alive=0)也保留
events <n> / ev ...                # 事件脚本一并存档
```

v2 加载时**忽略外部种子参数**，RNG 状态完全以存档为准。

## 分叉定位结论

同一段 v1 录制回放两次（不同种子），逐帧比对：

- **第 22 帧（检查点后第一个回放帧）即分叉**，且此后 69/69 帧全部不同。
- 该帧同时观察到三处独立偏差：
  1. 状态头 `rng` 不同（111 vs 222）——种子未存，随机流分叉；
  2. 状态头 `field` 为 `0 0 0 0`，而录制是 `0 -4 1.5 6`——力场被清零，
     所有存活粒子的速度/位置在这一帧立刻偏移；
  3. 状态头 `rate_acc` 为 `0.167`，而录制是 `0.5`——累积量被清零，发射时机错位。
- 池空洞由 `hole-test` 单独复现：4 槽（槽位 1 死亡）经 v1 存档后被压成 3 槽，
  原槽位 2 的粒子落到槽位 1；v2 则逐槽位（含 `alive=0`）精确还原。

## 修复后的确定性证据

- 同一段 v2 录制回放十次，十份帧日志 **md5 完全相同**（字节级一致）；
- 每份回放与原始录制的检查点后帧 **逐字节相同**；
- 故意传入不同外部种子、或不传种子走时间熵路径，结果仍恒定；
- 对照 v1 不传种子连跑三次得到三个不同 md5，确认缺陷与修复均真实有效。
