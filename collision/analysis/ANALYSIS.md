# 连续弹跳的闭式解、发散性与恢复系数选择

约定：y 轴向上，地面 y = 0，法向 n = (0,1)。入射角 θ 从地面法线量起
（θ=0 为垂直下落，θ→90° 为掠射）。重力大小 g，首次落地（第 1 次撞击）
前的速率为 V₀，法向/切向分量

v₁ₙ = V₀ cosθ（向下，取正值表示大小），v₁ₜ = V₀ sinθ。

恢复系数 e ∈ [0,1)，摩擦系数 μ ∈ [0,1]（μ 是每次撞击后**保留**的切向
速度比例，衰减量为 1−μ）。时间原点取在首次落地。

## 1. 分量碰撞响应

每次撞击把速度拆成法向、切向分别处理：

- 法向：vₙ⁺ = −e vₙ⁻（反转并按恢复系数缩放，e=0 即"趴下不弹"）
- 切向：vₜ⁺ = μ vₜ⁻（同向衰减，不反转）

这正是旧实现缺失的部分——旧逻辑把整个速度矢量镜像反弹，等效于
e=1、μ=1，所以看起来像撞墙，且碎片永远小幅弹跳。

## 2. 第 n 次反弹后的速度表达式

第 k 次撞击**前**（k=1 是首次落地），法向分量已被乘过 k−1 次 e，
切向分量已被乘过 k−1 次 μ：

```
vₙ,k⁻ = v₁ₙ e^(k−1)          vₜ,k⁻ = v₁ₜ μ^(k−1)
w_k    = |v_k⁻| = √(v₁ₙ² e^{2(k−1)} + v₁ₜ² μ^{2(k−1)})
```

第 k 次撞击**后**（即第 k 次反弹起跳时）：

```
vₙ,k⁺ = e v₁ₙ e^(k−1) = v₁ₙ e^k
vₜ,k⁺ = μ v₁ₜ μ^(k−1) = v₁ₜ μ^k
```

每弹一次，法向乘一次 e、切向乘一次 μ，两个分量各走各的几何级数——
这就是"单次反弹好算、连续反弹难"的全部结构。

## 3. 总弹跳次数与总时间的闭式

第 k 次撞击后的起跳速率是 v₁ₙ e^k，弹起再落地的飞行时长
（抛物线，起落到同一高度）：

```
Δt_k = 2 v₁ₙ e^k / g        k ≥ 1
```

第 k 次撞击发生的时刻（几何级数求和，e≠1）：

```
t_k = Σ_{j=1}^{k−1} Δt_j = (2 v₁ₙ / g) · e (1 − e^{k−1}) / (1 − e)
```

### 总时间（Zeno 极限）

```
T∞ = lim_{k→∞} t_k = 2 e v₁ₙ / ((1 − e) g)
```

飞行时长是公比 e 的几何级数，e<1 时级数和有限——**无限次弹跳被
压缩在有限时间内**，这是必须引入静止截断的根本原因：数学上粒子
在 T∞ 之后仍以无穷小幅度"弹跳"。

### 总弹跳次数

无截断的理想模型中，只要 e>0 法向级数就有无穷多项，N=∞。工程上
引入静止阈值 v_s（取 V₀ 的 1%）：撞击前速率 w_k ≤ v_s 时直接置零
休息，弹跳在第 N 次撞击终止，N 是满足下式的最小整数：

```
√(v₁ₙ² e^{2(N−1)} + v₁ₜ² μ^{2(N−1)}) ≤ v_s
```

没有初等闭式（两项底数不同），代码用闭式逐项迭代求 N；单看任一分量
的充分界为 N ≤ 1 + ln(v_s/v₁ₙ)/ln e（法向）和
N ≤ 1 + ln(v_s/v₁ₜ)/ln μ（切向），取两者较小者即安全上界。

## 4. 不可行性检查：什么参数组合下发散

| 组合 | 弹跳次数 | 总时间 | 结论 |
|---|---|---|---|
| e=1，任意 μ | ∞ | Σ Δt_k = ∞（Δt_k 不趋零） | **完全发散，永不静止** |
| 0<e<1，μ=1 | ∞（切向项恒为 v₁ₜ） | T∞ 有限 | 时间收敛但**永不满足速度阈值**，落地后无限滑行 |
| e=0 | 1 次撞击即停 | 0 | 一次趴下，无弹跳感 |
| 0<e<1，μ<1 | 阈值截断后有限 | T∞ 有限 | 唯一可行区间 |

证明要点：

1. Δt_k = 2v₁ₙe^k/g。e=1 时 Δt_k 恒为常数，Σ 发散，T∞=∞。
2. e<1 时 e^k→0，几何级数 Σ e^k = e/(1−e) 收敛，T∞ 有限；
   但 e→1⁻ 时 1/(1−e) 发散，**级数收敛速度趋于零**——e=0.9 时
   T∞ = (2v₁ₙ/g)·e/(1−e) = 18 v₁ₙ/g，对 V₀=10、θ=15° 是 17.7 s；
   e=0.99 时 e/(1−e)=99，T∞ 达 195 s。
   加摩擦救不了它：摩擦只衰减切向分量，飞行时长完全由法向决定。
3. 切向序列 v₁ₜ μ^(k−1) 在 μ=1 时恒等于 v₁ₜ。只要
   v₁ₜ > v_s（任何非零入射角都成立），速率阈值永远不被满足，
   粒子在地面上永远滑动——**摩擦必须严格小于 1**。
4. 两个分量都严格衰减（e<1 且 μ<1）时，w_k→0，阈值必在有限次
   撞击内被穿过，N 有限。

规避约束：**e ≤ e_max < 1 且 μ < 1，两者都是硬约束，缺一不可。**

## 5. 用"落地后 1 秒内静止"反解 e 的上限

静止阈值 v_s = 0.01 V₀，截止时间 T = 1 s，V₀ = 10 m/s，g = 9.8，μ = 0.8。

### 充分界（Zeno，与 θ 有关，保守但有闭式）

要求 T∞ ≤ T：

```
2 e v₁ₙ / ((1−e) g) ≤ T
⇒ e ≤ gT / (gT + 2 v₁ₙ)
```

入射角越小（越接近垂直）v₁ₙ 越大，界越严。θ=15° 时 v₁ₙ=9.659：

```
e ≤ 9.8 / (9.8 + 2·9.659) = 0.3366
```

### 精确界（离散截断，扫描闭式）

实际静止发生在 t_N（最后一次撞击时刻），不必等满 T∞。对三档入射角
扫描 e（步长 0.0005），取满足 t_N ≤ 1 s 的最大 e：

| 入射角 θ | v₁ₙ | 精确 e_max | Zeno 充分界 |
|---|---|---|---|
| 15° | 9.659 | **0.3365** | 0.3366 |
| 45° | 7.071 | 0.4090 | 0.4090 |
| 75° | 2.588 | 0.6540 | 0.6540 |

最严档（15°）决定全局上限。两者几乎重合，因为阈值 1% 很小，
最后一跳的时间可以忽略。

## 6. 取舍：用 N(e) 与 T(e) 两条曲线定系数

- e 大：弹跳自然、次数多，但 T(e) 以 1/(1−e) 发散，静止慢；
- e 小：T(e)≈2e v₁ₙ/g 很短，但 e=0 一次就趴下，没有弹跳感。

`bounce_report.html` 前两张图给出两条曲线：N(e) 单调上升（对数轴上
近似线性，N∝ln(1/e)），T(e) 在 e→1 时垂直上扬。可行设计点是
T(e) 曲线与 1 s 截止线的交点左侧、且 N 仍有十几次弹跳的区域。

- 硬上限：e_max = 0.3365（15° 档）
- 工程取值：**e\* = 0.33，μ = 0.8**——在硬上限下留出约 2% 余量，
  吸收帧步长抖动与浮点误差，同时三档入射角都能弹 15 次以上。

## 7. 三档入射角验证（数值，见 `bounce_analysis.py`）

对闭式解和时间步进仿真（dt = 10⁻⁴ s，与 C 模块同一套规则）做交叉校验：

| θ | 弹跳数 N | 静止时间 t_N | 末次撞击速率比 | ≤1 s | ≤1% | 仿真误差 Δt | 仿真误差 Δw |
|---|---|---|---|---|---|---|---|
| 15° | 15 | 0.9709 s | 0.00911 | ✓ | ✓ | 7.9e-4 | 8.9e-4 |
| 45° | 20 | 0.7108 s | 0.00815 | ✓ | ✓ | 1.1e-3 | 3.8e-4 |
| 75° | 21 | 0.2602 s | 0.00891 | ✓ | ✓ | 8.4e-4 | 1.4e-5 |

误差都在一个 dt 量级，闭式与仿真一致。C 自检（`make test`）复现
同样的弹跳数（15/20/21）与静止时间。

### 超界反例：e = 0.9，θ = 15°

1 s 时速率仍有初速的 **28.15%**（远超 1%），直到**第 44 次反弹后**
才静止，t_N = 17.57 s（Zeno 极限 17.74 s）。C 侧 e=0.95 的对照
更极端：89 次反弹、36.8 s 才停。这就是第 4 节发散性的有限截断版本。
