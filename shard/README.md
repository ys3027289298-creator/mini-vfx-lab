# shard

碎片翻滚角速度的指标化选峰，取代纯随机角速度。`make test` 跑自检。

## 指标

R(ω) = 可见翻转次数 / 碎片可见时长，单位 flips/s：

```
R(ω) = ω/2π · exp(-(ω·dt/θc)²)
```

`ω/2π` 是名义翻转率；指数项是视觉相干性——单帧步进角 `ω·dt` 越大，
时间混叠越严重，方向不可辨、退化成模糊块。`dt = 1/60 s`，`θc = π`。

## 峰的存在性（不靠感觉）

- ω→0：R ≈ ω/2π → 0，碎片不翻转；
- ω→∞：高斯衰减压过线性增长，R→0，碎片单帧转太多圈只剩模糊块；
- R 在 (0,∞) 上连续为正，必有峰；令 dR/dω=0 得唯一解析峰
  `ω* = θc/(√2·dt) ≈ 133.3 rad/s`（约 21.2 rev/s），与对数网格扫描结果
  互相验证（偏差 <1%，自检 `peak_matches_analytic`）。

## 尺寸挂钩与乘积区间

边缘线速度恒定：`ω·s = K`，小碎片转得快。以参考尺寸 12 px 标定：

| 量 | 值 |
|---|---|
| 峰位 ω* | 133.26 rad/s |
| 接受带（R ≥ 0.9·Rmax） | ω ∈ [92.63, 178.66] rad/s |
| 设计常数 K = ω*·s | 1599.08 rad·px/s |
| **乘积区间 P = ω·s** | **[1111.60, 2143.87] rad·px/s** |
| 可支持尺寸范围 | [8.95, 17.26] px |

`shard_assign` 每次分配都检查 P 是否落在区间内，越界即重扫（最多 16 次），
尺寸本身超出可支持范围则直接拒绝，不返回“近似可以”的值。
