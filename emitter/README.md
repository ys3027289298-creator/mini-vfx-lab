# emitter

`make test` 跑自检；`make lab` 重新生成降级曲线与三档发射率数据
（CSV/PNG 写到仓库根目录的 `artifacts/`）。

## 平滑降级模型

固定参数取当前自测中的容量与寿命：

- 硬上限 `K = 64`
- 粒子寿命 `τ = 1 s`
- 帧长 `dt = 1/60 s`
- 开始降级的占用率 `z₀ = 0.75`，即 `N₀ = 48`
- 三档名义发射率 `R = 64, 128, 256` 个/秒，对应负载比 `ρ = Rτ/K = 1, 2, 4`

令占用率 `z = N/K`，逼近程度归一化为

```text
u(N) = clamp((z - z₀) / (1 - z₀), 0, 1)
```

发射率保留比例和降幅写成幂函数：

```text
s(N;γ) = (1-u)^γ
D(N;γ) = 1-s = 1-(1-u)^γ
R_eff  = R · s(N;γ)
```

`γ` 越大，在刚进入降级区后砍得越狠；`γ=1` 是线性降幅。

## 稳态与反解

连续总体模型为

```text
dN/dt = R·s(N;γ) - N/τ
```

稳态时 `dN/dt=0`，由 Little 定律形式得到

```text
N̄ = Rτ · ((K-N̄)/(K-N₀))^γ
z̄ = ρ · ((1-z̄)/(1-z₀))^γ
```

若要求最大档 `ρ_max=4` 的稳态恰好落在设计占用率 `z_d=56/64=0.875`，则

```text
γ_req = ln(z_d/ρ_max) / ln((1-z_d)/(1-z₀))
      = ln((7/8)/4) / ln((1/8)/(1/4))
      ≈ 2.19265
```

按半档取 `γ=2.5`。此时三档解析稳态为：

| 发射率 | 解析稳态粒子数 | 占上限 |
|---:|---:|---:|
| 64/s  | 49.56 | 77.4% |
| 128/s | 52.77 | 82.5% |
| 256/s | 55.33 | 86.5% |

均不超过 `K=64`。

## 陡度取舍

`稀疏可感度` 定义为 `N=48→56` 区间内的平均发射降幅：

```text
S(γ) = mean(D), u∈[0,0.5]
     = 1 - [1-(1-0.5)^(γ+1)] / [0.5(γ+1)]
```

| γ | 最大档稳态 N̄ | 超过设计预算56 | 稀疏可感度 S |
|---:|---:|---:|---:|
| 0.5 | 63.03 | 7.03 | 0.138 |
| 1.0 | 60.24 | 4.24 | 0.250 |
| 1.5 | 58.05 | 2.05 | 0.341 |
| 2.0 | 56.48 | 0.48 | 0.417 |
| **2.5** | **55.33** | **0.00** | **0.479** |
| 3.0 | 54.45 | 0.00 | 0.531 |
| 3.5 | 53.76 | 0.00 | 0.575 |
| 4.0 | 53.20 | 0.00 | 0.613 |

因为 `s(K)=0`，硬上限稳态溢出在任意 `γ>0` 都为零；只看硬上限无法选出有限
陡度。因此用 `N_d=56` 作为给离散取整和在途粒子预留余量的设计预算：溢出曲线在
`γ≈2.19` 处归零，而稀疏度随 `γ` 单调上升。取满足半档网格的最小值 `γ=2.5`，
再陡只会额外增加稀疏感。

## 三档实跑结果

`make test` 中的固定寿命整数粒子模拟跑 `1200` 帧。稳定判据：以最后 `240` 帧
均值为稳态，从降级首帧之后找到最后一个偏离该均值超过 `±3` 的帧，其后第一帧
记为稳住；`frames` 是从降级开始到稳住的帧数。

| 发射率 | 降级开始帧 | 稳住帧 | 所需帧数 | 峰值 | 末240帧均值 | capacity dropped |
|---:|---:|---:|---:|---:|---:|---:|
| 64/s  | 46 | 64  | **18**  | 56 | 50.40 | 0 |
| 128/s | 23 | 444 | **421** | 60 | 53.65 | 0 |
| 256/s | 12 | 507 | **495** | 62 | 56.43 | 0 |

三档峰值和末态均值都没有超过 `64`，且没有触发容量丢弃。较长的严格稳定时间
来自所有粒子都使用相同的 `1 s` 寿命所形成的同批出生/死亡共振；它表现为有界
波纹，而不是顶满上限后的截断卡顿。

若只跑推导所用的平滑总体帧递推

```text
N_{f+1} = N_f + dt(R·s(N_f) - N_f/τ)
```

并以进入解析稳态 `±0.5` 且不再离开为稳定判据，三档分别需要 **6、9、6 帧**。
这组数字与逐粒子严格判据一起记录在 `../artifacts/degrade_runs.csv`。
