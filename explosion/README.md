# explosion

爆炸爆发发射器与寿命分布分析模块。复现并定位"首帧 800 颗、随后掉到 200、
第 3 秒全空"的粒子断崖问题，给出寿命分布修正并用数据验证衰减曲线变平滑。

## 背景：缺陷由两个独立原因叠加而成

1. **容量丢弃**：帧 0 爆发请求 800 颗，粒子池只有 200 个槽位（对应
   `emitter` 的 `MAXP`），600 颗当场被丢弃，可见数立刻是 200。
2. **固定寿命**：每颗粒子寿命在生成时取同一个定值 2.0 s、没有分布，
   于是全部 200 颗在第 60 帧（t=2.0 s）同一帧消亡，单帧掉 100%，形成断崖。

第 2 点才是"某一帧掉一半"的根因。本模块在保留容量约束的前提下，把寿命从
定值改为按分布采样（指数 / 均匀），死亡时刻被摊开，衰减曲线变平滑。

## 构建与自测

```sh
make test
```

15 项检查覆盖：三种寿命采样器的统计性质（范围、均值、右偏）、容量丢弃计数、
固定寿命整批同帧消亡的断崖、指数/均匀模式不存在单帧掉一半、RNG 确定性。

## 仿真与分析流水线

```sh
make run OUT=../artifacts/explosion_v2          # C 引擎产出 CSV
../.venv/bin/python -I ../tools/analyze_explosion.py \
    --in-dir ../artifacts/explosion_v2 \
    --out-dir ../artifacts/explosion_v2/analysis
```

场景参数（三种模式完全一致，仅寿命采样不同，见 `src/explosion.c`）：

| 参数 | 值 |
|---|---|
| 帧步长 / 帧数 | 1/30 s，375 帧（12.5 s） |
| 池容量 | 200 |
| 帧 0 爆发 | 800 颗（接受 200，丢弃 600） |
| 后续发射 | 帧 1–6 每帧 30 颗 |
| 固定寿命 | 2.0 s |
| 均匀寿命 | U(0.8, 3.0) s |
| 指数寿命 | 均值 1.5 s，12 s 截断 |

每个模式产出四个 CSV：`frames.csv`（逐帧总量/亮度/丢弃）、`batches.csv`
（逐帧×逐批存活数与平均亮度）、`snaps.csv`（逐颗粒位置快照）、
`particles.csv`（出生台账：每个被接纳粒子的寿命与初速度，槽位复用不覆盖）。

分析产物（`analysis/`）：

- `fig1_decay.png`：三模式存活总数与平均亮度随时间曲线，标出容量丢弃与断崖；
- `fig2_lifetime.png`：寿命直方图 + 经验 CDF 对理论 CDF 的 KS 检验；
- `fig3_batch_grid_<mode>.png`：t=0/1/2/3 s 四张快照，每张附各批存活数与
  平均亮度表；
- `fig4_batch0_decay.png`：第 0 批从生成到消亡的存活比例，实测曲线与寿命
  分布对应的理论存活函数对照；
- `batch_snapshots_*.csv`：快照时刻的逐批机器可读表；
- `analysis_summary.json`：寿命统计、KS 距离、最坏单帧跌幅、断崖帧清单。

## 结论

| 模式 | 寿命均值 | CV | 最坏单帧跌幅 | 断崖帧（≥50%） | 判定 |
|---|---|---|---|---|---|
| 固定 2.0 s | 2.00 | 0.00 | 100%（帧 60） | [60] | 断崖 |
| 均匀 U(0.8,3.0) | 1.93 | 0.34 | 25.0% | 无 | 平滑 |
| 指数 Exp(1.5) | 1.48 | 1.05 | 16.7% | 无 | 平滑 |

分布选择用 KS 检验自证：指数样本对指数 CDF 的 KS=0.055、对均匀 CDF 的
KS=0.420；均匀样本对均匀 CDF 的 KS=0.053、对指数 CDF 的 KS=0.415——
形状对不上现实（错误分布族）时 KS 明显变大。指数分布右偏、众数贴近 0，
符合爆炸中大量粒子快速熄灭、少数长尾余烬的物理直觉，是推荐的默认选择。
