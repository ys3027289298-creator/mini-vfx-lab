# 共享粒子池：可写区间判据与隔离粒度反解

现象：两组特效同时播放时，一组粒子继承另一组的颜色。根因是两个系统共用同一个裸池、
写区间在同一批槽位上相交，后写者覆写了先写者的颜色字段。本文给出：

1. 每个槽位的**属主**与**写权限**的形式化判据；
2. 如何用并发写次数反解必须的隔离粒度；
3. 峰值内存与冲突次数两条曲线如何共同定粒度；
4. 三档并发 `K=2 / 4 / 8` 各实跑一次的结果：**冲突全部为 0**，并给出相对完全隔离的内存比例。

实现为同目录 C 自检模块 `src/pool.c`（确定性工作负载，无随机种子问题），
曲线数据 `../artifacts/pool_curves.csv`，汇总 `../artifacts/pool_summary.json`，
三档原始日志 `../artifacts/run_tier{2,4,8}.txt`。

## 1. 共享池的可写区间判据

池有 `N` 个槽位 `j ∈ {0,…,N−1}`，属主标签粒度为 `g`（每个属主块含 `g` 个槽），
块号

```
b(j) = ⌊ j / g ⌋
```

设时刻 `t` 每个块有标签 `τ_b(t) ∈ {⊥, 0, 1, …, K−1}`（`⊥` 为空闲）。

**槽位属主：**

```
O_j(t) = τ_{⌊j/g⌋}(t)
```

系统 `s` 持有的块集合与可写区间并集：

```
B_s(t) = { b | τ_b(t) = s }
I_s(t) = ⋃_{b∈B_s(t)} [ b g , (b+1)g )
```

分配器必须始终满足一块不事二主的不变量：

```
∑_{s=0}^{K−1} 1[ b ∈ B_s(t) ] ≤ 1          对每个 b, t
```

**写权限（可写判据）：**

```
π_s(j,t) = 1  ⇔  O_j(t) = s  ⇔  j ∈ I_s(t)
```

代码中对应 `can_write(owner, g, s, j) = (owner[j/g] == s)`；每次写入都过这道闸门，
闸门失败计入 `denials`。

记系统 `s` 在 tick `t` 实际写入的槽集为 `W_s(t) ⊆ I_s(t)`，槽位的并发写多重度为

```
μ_j(t) = ∑_s 1[ j ∈ W_s(t) ]
```

冲突槽次与覆写余量：

```
C = ∑_t ∑_j 1[ μ_j(t) ≥ 2 ]
E = ∑_t ∑_j max(0, μ_j(t) − 1)
```

于是零冲突判据为

```
C = 0  ⇔  μ_j(t) ≤ 1  (∀j,t)
      ⇔  W_s(t) ∩ W_u(t) = ∅  (∀ s ≠ u, ∀t)
```

即"任意两系统并发时冲突为零"等价于所有并发写区间两两不交。
模拟里还有一道独立的颜色回读审计：每系统写自己的颜色令牌 `s+1`，
全部写完后回读，颜色不等于本系统令牌即计入 `color_inheritance`——
这正是用户看到的"继承另一组颜色"。

### 连续区间（静态隔离带）特例

若系统 `s` 的写区间为 `[a_s, a_s + d_s(t))`，相邻带起点间距为 `g`（`a_s = s·g`），
则不交条件是

```
s·g + d_s(t) ≤ (s+1)·g   ⇔   d_s(t) ≤ g     (∀ s,t)
```

## 2. 用并发写次数反解隔离粒度

工作负载：每系统峰值 `D = 64` 粒子，`T = 384` tick，错峰三角爆发
（相位 `24s`，周期 192），`d_s(t)` 为系统 `s` 在 tick `t` 的并发写次数。

### 2.1 静态独占带：冲突曲线反解出的硬下界

由上面的不交条件：

```
g_req = max_{s,t} d_s(t) = D = 64
```

即静态带必须按单系统峰值 64 预留，`g < 64` 时必有某个处于非末尾位置的系统
写穿自己的带、落到下一系统的槽上。实测冲突曲线（384 tick 累计冲突槽次）：

| `g`（带间距） | 1 | 2 | 4 | 8 | 16 | 32 | **64** |
|---|---:|---:|---:|---:|---:|---:|---:|
| K=2 | 6492 | 6224 | 5680 | 4562 | 3412 | 1832 | **0** |
| K=4 | 19614 | 18938 | 17534 | 14500 | 10822 | 5496 | **0** |
| K=8 | 48854 | 47436 | 44440 | 37386 | 26030 | 12824 | **0** |

三档都只在 `g = D = 64` 处归零，与反解一致。更糟的公共基址裸池（所有系统都从 0
开始写，即 `g = 0`）直接复现颜色污染：K=2/4/8 分别有
**6,758 / 20,274 / 50,224** 个冲突槽次，且颜色回读污染数与之相等。

### 2.2 共享属主块池：并发写次数反解峰值容量

细分配时以 `g` 为块单位，系统 `s` 在 tick `t` 需要的块数

```
r_s(t;g) = ⌈ d_s(t) / g ⌉
```

存在两两不交分配的充要条件（块池总块数为 `B`）：

```
∑_s r_s(t;g) = ∑_s ⌈d_s(t)/g⌉ ≤ B        (∀t)
```

按峰值配置块数，得到**峰值槽位曲线**：

```
M_g(K) = g · max_t ∑_{s=0}^{K−1} ⌈ d_s(t) / g ⌉
```

只要池容量取 `M_g`、分配器保证一块一属主、每次写入执行 `π_s` 闸门，
则对任意 `g ≥ 1` 都有 `C = 0`——零冲突由判据构造性保证，而不是靠调大粒度。

相对完全隔离（每系统一个 `D` 槽私池，共 `K·D` 槽；K=2 时正好是单池的两倍）：

```
ρ_slot(K,g) = M_g(K) / (K·D)
```

实测：

| `g` | 1 | 2 | 4 | 8 | 16 | 32 | 64 |
|---|---:|---:|---:|---:|---:|---:|---:|
| K=2 | 79.69% | 81.25% | **81.25%** | 87.50% | 100% | 100% | 100% |
| K=4 | 58.59% | 59.38% | **60.94%** | 65.63% | 75.00% | 87.50% | 100% |
| K=8 | 37.11% | **37.50%** | 39.84% | 45.31% | 50.00% | 68.75% | 100% |

`g = 64 = D` 时 `M_g = K·D`，共享池退化为完全隔离，验证了曲线端点。

### 2.3 用总占地曲线选最优点 `g*`

粒度越细，内部碎片越小，但属主标签越多。设粒子槽 `S = 32 B`、每块标签
`T_tag = 4 B`，总峰值占地

```
F_g(K) = S·M_g(K) + T_tag·M_g(K)/g
ρ_byte(K,g) = F_g(K) / (S·K·D)
g* = arg min_{g∈{1,2,4,8,16,32,64}} F_g(K)
```

`F_g` 是"碎片随 `g` 上升、标签数随 `g` 下降"两条力量之和，呈 U 形，
据此选出 `g*`（并列时取更细粒度）：

| K | 并发写峰值 `A=max_t Σd_s` | `g*` | 峰值槽 `M_g*` | 完全隔离 `K·D` | **槽位比** | **含标签字节比** |
|---|---:|---:|---:|---:|---:|---:|
| 2 | 102 | **4** | 104 | 128 | **81.25%** | **83.79%**（3432 / 4096 B） |
| 4 | 150 | **4** | 156 | 256 | **60.94%** | **62.84%**（5148 / 8192 B） |
| 8 | 190 | **2** | 192 | 512 | **37.50%** | **39.84%**（6528 / 16384 B） |

注意 `g=64` 时字节比为 100.2%：完全隔离的私池不需要属主标签，
而粗块共享池仍要为标签付费——这是"完全隔离最安全"之外一个容易漏掉的反向成本。

## 3. 三档并发各跑一次：冲突必须为零

命令（每档一次正式运行，完整输出存于 `../artifacts/run_tierK.txt`）：

```sh
./pool tier 2
./pool tier 4
./pool tier 8
```

三档结尾的审计行完全同构：

```
run=owner_block_pool collisions=0 permit_denials=0 color_inheritance=0 double_writes=0
zero_conflict=1
all_ok=1
```

| 并发档位 | collisions | permit_denials | color_inheritance | double_writes | 峰值槽位比 | 峰值字节比 |
|---|---:|---:|---:|---:|---:|---:|
| **K=2** | **0** | 0 | **0** | 0 | **0.8125** | **0.8379** |
| **K=4** | **0** | 0 | **0** | 0 | **0.6094** | **0.6284** |
| **K=8** | **0** | 0 | **0** | 0 | **0.3750** | **0.3984** |

相对完全隔离：两系统时峰值内存约为完全双私池的 **81%（槽位）/ 84%（含标签）**；
八系统错峰时降到 **37.5% / 39.8%**。并发档位越高，统计复用收益越大。

### "任意两系统"的穷举配对验证

除三档整体运行外，自检把 8 种相位的工作负载两两配对
（`C(8,2)=28` 对），每对再扫全部 7 种粒度、跑满 384 tick：

```
every_pair_zero_conflict=1
pair_configs_checked=196        # 28 对 × 7 粒度
all_ok=1
```

这正是判据 `W_a(t) ∩ W_b(t) = ∅` 在所有相位对上的直接验证。

## 4. 结论：粒度怎么定

1. **冲突次数曲线给下界**：若只做静态区间隔离，必须 `g ≥ D = 64`，
   代价是 `K·D` 槽（K=2 即内存翻倍），曲线在 64 处才触零。
2. **峰值内存曲线给最优点**：改成"属主标签 + 块空闲表 + 每次写入过
   `π_s(j,t)` 闸门"的细分配共享池后，所有粒度下实测冲突、越权写入、
   颜色继承均为 0；再用总占地 `F_g` 的 U 形曲线选 `g* = 4（K=2/4）`、
   `g* = 2（K=8）`。
3. **最终保证**：容量满足 `M_g = g·max_t Σ⌈d_s(t)/g⌉`，
   且一块一属主 + 写权限闸门，则任意两系统并发 `C = 0`。
   三档实跑峰值内存分别为完全隔离的 **81.25% / 60.94% / 37.50%**（槽位口径）。
