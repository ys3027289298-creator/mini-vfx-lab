# texalias

旋转粒子贴图的双线性采样锯齿测量：锯齿幅度与贴图尺寸、旋转角、屏幕尺寸
的关系，以及 1 px 阈值下的最小贴图边长反解。`make test` 跑自检，
数据落在 `results/`。

## 测量模型

记号：贴图边长 N texel，屏幕边长 S px，r = N/S（每像素覆盖的 texel 数），
旋转角 theta，边缘锯齿幅度 e（屏幕像素，取 alpha 0.5 等值线相对解析真值
的最大偏差；另报 RMS）。

三个探针，全部按自身局部坐标系定义，解析真值与 theta 无关，因此角度引入
的差异全部是重采样误差：

| 探针 | 烘焙方式 | 隔离的误差源 |
|---|---|---|
| line | 半平面 1 texel 线性 ramp | 纯旋转（等值线度量） |
| area | 圆盘，texel 存单元面积覆盖率（SDF ramp） | 曲率 + 旋转 |
| hard | 圆盘，texel 中心 0/1 硬采样 | 曲率 + 旋转 + 烘焙台阶 |

渲染：UV 采样网格绕中心旋转 theta 后做 2x2 双线性；映射约定保证
N=S、theta=0 是恒等取回（无半 texel 偏移）。真值用 16x16 超采样的
解析覆盖率，在屏幕分辨率直接生成。

## 关键结论（均由自检断言锁定）

1. **旋转本身不制造直边等值线锯齿。** 双线性插值精确重构任意方向的
   仿射函数，line 探针的 0.5 等值线在 0/5/30/45 度全部精确（误差 0）。
   旋转只让 ramp 带内的像素值产生抖动（theta=45 度 val_rms 0.50），
   但等值线位置不变。
2. **静止干净、旋转显锯齿的真正来源是曲率与烘焙，不是旋转角本身。**
   圆盘切线只在四个轴点与网格对齐，theta=0 时其余弧段已有曲率误差；
   旋转改变各弧段与网格的亚 texel 相位，让误差重新分布并出现可见波动。
3. **硬 alpha 有去不掉的误差地板。** hard 探针相对平滑真值的误差在
   r=2 时仍有约 0.3-0.5 px，因为台阶烘焙在源头就丢了覆盖率信息，
   加大贴图只能把台阶变密，不能消除。面积烘焙（SDF/覆盖率）没有这个
   地板，应作为粒子贴图的默认烘焙方式。
4. **标度律分两个区间**（S=256 实测，r=1 标度不变性在 S=128/256/512
   上验证，误差为固定像素数）：
   - 缩小/临界区 r <= 1：e(px) ≈ C(theta)/r = C(theta)·S/N，
     即 texel 空间幅度 A = e·r 恒定（拟合指数 p = -0.8 ~ -0.97）。
     C(theta) 实测：area 探针 0.10-0.18，hard(对平滑真值) 0.44-0.77。
   - 放大区 r > 1：双线性在 texel 节点误差为零，屏幕误差收敛到亚像素
     相位地板（area ≈ 0.15 px，hard ≈ 0.55 px），继续加大贴图没有收益。
5. **r < 1 是走样而非平滑抖动**：像素 footprint 覆盖不足一个 texel，
   双线性无法替代 mipmap；小贴图 + 旋转的组合必须配 mipmap。

## 最小贴图边长反解（阈值 1 px）

由 r <= 1 的标度律反解：

    N_min = C(theta) · S

实测 C(theta)（area 烘焙，edge_max）：

| theta | 0 deg | 5 deg | 30 deg | 45 deg |
|---|---|---|---|---|
| C(theta) | 0（对齐恒等） | 0.149 | 0.176 | 0.155 |

三档旋转角在 S=256、紧工作点 N=32（r=0.125）的裁决（程序输出）：

    theta=5   e=1.048 px  OVER -> required N=48
    theta=30  e=1.100 px  OVER -> required N=48
    theta=45  e=0.803 px  ok (N=32)

注意 45 度不是最差档——最差相位随角度和弧段位置变化，30 度档在本
探针几何下取得最大 C。通用工程取值：area 烘焙取 C=0.18 上包络，
即 **N_min ≈ 0.18·S**（256 px 粒子 => 48 texel，取 2 的幂 => 64）；
hard 烘焙取 C=0.77，即 N_min ≈ 0.77·S，且永远带着约 0.5 px 地板。

## 锯齿幅度 / 采样成本两条曲线

见 `results/sizing_curves.png`（数据 `results/edge_error.csv`，
拟合 `results/fit.py`）：

- 锯齿曲线：e 随 N 在 r<=1 段按 1/r 下降，r>1 段压到相位地板后走平。
- 成本曲线：双线性每像素固定 4 taps，与 N 无关；成本随 N 涨的是
  显存/缓存占用 4·N² 字节（RGBA8）。两条曲线的交点在 r≈1 附近——
  超过 r=1 之后内存继续按平方涨，锯齿却不再改善，这就是定尺寸的
  自然上界。

## 文件

- `src/texalias.c` — 探针烘焙、旋转双线性渲染、误差度量、标度律断言
- `results/edge_error.csv` — 全部配置的 edge/value 误差
- `results/fit.py` — 分区幂律拟合与定尺寸系数（`python3 -I`）
- `results/plot.py` — 双曲线图（依赖 matplotlib，user site 运行）
