# softground

粒子与地面交叉的软过渡（soft particle）：按片元离地高度做 alpha 衰减，替代硬切边。

## 关系式

设：

- `s`：粒子屏幕尺寸（像素直径），`s = 2rK`，`r` 世界半径，`K` 像素/世界单位
- `δ`：粒子中心到地面的深度差（世界单位，中心在地面上方为正）
- `λ`：衰减长度（世界单位），片元 `alpha = clamp(y/λ, 0, 1)`，`y` 为片元离地高度

沿过粒子中心的竖直采样线，圆盘覆盖 `y ∈ [δ−r, δ+r]`，过渡带为 `y ∈ (0, λ)`，故过渡宽度为两区间交集：

```
W(s, δ) = K · max(0, min(λ, δ+r) − max(0, δ−r))   [像素]
```

宽度由粒子屏幕尺寸（经 `r = s/2K`）与中心-地面深度差 `δ` 共同决定，不能拍固定像素数。

## 反解衰减参数

设计要求：中心贴地（δ=0）时过渡带占半个屏幕尺寸，即 `W(s,0) = s/2`。
代入关系式：`K·min(λ, r) = s/2 = rK` → **λ = r**（一般形式 λ = 2βr，β 为目标占比，取 β = 1/2）。

边界约束：粒子完全离开地面（δ ≥ r）时不得淡化，且在接触处连续，故有效衰减长度随离地收窄：

```
λ_eff = clamp(r − δ, 0, λ)
```

## 边界

- `δ ≤ −r`（完全埋入）：所有片元 `y ≤ 0` → α = 0
- `δ ≥ r`（完全在地面上方、未交叉）：`λ_eff = 0` → α ≡ 1，无任何淡化

`make test` 跑自检：三档尺寸量过渡像素、深度差扫描对照公式预测、两条边界，并打印硬切边/软过渡对照图。
